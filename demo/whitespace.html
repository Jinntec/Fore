Whitespace

The whitespace property of fx-bind cleans up the string value of a node whenever it changes. It is applied during recalculate, so a calculate, constraint or any other expression that reads the node already sees the cleaned value.

  • preserve: leave the value untouched (default)
  • remove: remove all whitespace
  • trim: remove leading and trailing whitespace
  • collapse: replace each run of whitespace with a single space
  • normalize: trim and collapse combined

It only applies to nodes with simple content (no child elements) and is not an expression. Whitespace is any character with the Unicode property WSpace=Y.
