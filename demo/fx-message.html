fx-message

There are 3 types of messages:

  • By default firing an fx-message action displays a auto-closing toast message.
  • With level="sticky" the toast will become sticky (not closing) while displaying a close icon.
  • level="modal" displays a modal message.

Appearance

level says how important a message is, appearance how it is presented. Both can be combined. Every message gets the CSS class appearance-<name> (appearance-toast, appearance-banner) which you can style from your own CSS.

  • appearance="toast" - the default look: a small box in the corner.
  • appearance="banner" - a full-width bar at the top of the page with a close button.

Also refer to the native <dialog> element (used with the fx-show/fx-hide actions) if more complex messages are wanted, styled content or button logic is required.
